# FruugoShopPulse

一个基于 **Python + Selenium (Undetected Chromedriver)** 开发的多线程跨境电商数据提取工具。专门用于批量检测 **Fruugo** 平台的店铺运营状态（正常、假期、闭店）并提取其在售的 SKU 数量。

项目配备了直观的 **Tkinter GUI 界面**，支持通过导入 Excel 文件的形式进行自动化作业，并具备完善的防反爬与多站点交叉验证机制。

---

## 🛠️ 核心功能

* **智能状态判定与色彩高亮**：
自动识别店铺状态并实时写入 Excel，根据不同状态自动进行单元格颜色填充：
* 🟩 **一切正常** (`#90EE90` 浅绿色)：店铺正常营业，商品处于 "In stock" 状态。
* 🟨 **假期模式** (`#FFFF00` 黄色)：店铺开启了假期模式，或商品显示为 "Currently unavailable"。
* 🟥 **闭店** (`#FF0000` 红色)：店铺已关闭，无法获取商品信息。


* **SKU 数量精确提取**：
自动定位店铺 `SALE` 区域的文本，过滤并清洗掉千分位符（`,`、`.`）及杂质字符，提取纯数字的在售 SKU 总数。
* **灵活的站点适应机制**：
* **单站点店铺**：若 Excel 中指定了特定站点（如 South Korea, Poland 等），程序将直接精确访问该国家的对应域名（如 `fruugo.kr`, `fruugo.pl`），大幅提升检测效率。
* **多站点店铺**：默认通过英国站点（`fruugo.co.uk`）进行检索，若主站点未匹配到商品，会自动切换至芬兰、瑞士等其他国家站点进行**交叉验证**，有效防止因单一站点异常导致的状态误判。


* **强大且多维的防反爬设计**：
* 使用 `undetected-chromedriver` 底层框架，动态绕过 WebDriver 自动化浏览器特征检测。
* **多线程数据隔离**：为每个线程单独在 `C:/chrome_profiles/` 下创建独立的 Chrome 用户数据目录（Profile），并随机分配 `User-Agent`。
* **行为拟人化延迟**：内置随机睡眠机制。每检查完 3 个店铺，程序会自动触发一次长达 `15~30秒` 的深度反爬休息，降低被平台封锁 IP 的风险。


* **可视化交互界面**：
集成 Tkinter 界面，支持动态配置线程数，并将系统标准输出（`sys.stdout`）重定向至界面文本框，实现日志的实时滚动刷新。

## 🚀 环境准备与安装

### 1. 依赖库安装

请确保本地 Python 环境为 3.x 版本，然后打开终端（Terminal）运行以下命令安装所需的第三方库：

```bash
pip install pandas undetected-chromedriver selenium openpyxl

```

### 2. 浏览器驱动配置

1. 确保本地已安装 Google Chrome 浏览器。
2. 下载与你当前 Chrome 浏览器大版本号**完全一致**的 `chromedriver.exe`。
3. 将下载好的 `chromedriver.exe` 放置在与 `cate.py` **相同的文件夹目录下**。

---

## 💻 使用指南

### 1. 启动工具

在终端或命令行环境中，切换到项目目录并执行主脚本：

```bash
python cate.py

```

### 2. 界面操作步骤

1. 点击 **"选择Excel文件"** 按钮，导入准备好的店铺清单表格（`.xlsx`）。
2. 在 **"线程数"** 输入框中设置并发线程数（默认为 5，建议设置为 3-5。过高的线程数可能导致本地 CPU 负载过高或触发平台严格风控）。
3. 点击 **"开始运行"**，下方日志文本框将即时打印各个线程的初始化状态与店铺爬取日志。
4. 如需中途终止任务，可点击 **"结束运行"** 按按钮。

> 💡 **数据安全提示**：
> 本程序内置了线程锁（`threading.Lock`）。每当一个线程完成单个店铺的检测，都会动态获取锁并**即时保存**数据至原 Excel 文件中。因此，即使程序中途因网络原因中断，已跑完的数据也不会丢失。
